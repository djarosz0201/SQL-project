# SQL Course Final Project: User Activity & Email Engagement Analysis

## Project Overview
This repository contains the final project for a SQL course. The main objective of the project is to collect, query, and analyze data related to user account creation dynamics and user activity, with a strong focus on email marketing engagement (sent, opened, and clicked messages). 

By leveraging SQL, this project aims to uncover patterns in user behavior, optimize communication strategies, and segment users for targeted insights.

---

## Key Objectives & Research Questions
* **Account Dynamics & Verification:** Analyze the time gaps between account creation, email verification, and initial activity.
* **Email Engagement:** Track and measure email performance metrics (delivery, open rates, and click-through rates).
* **Subscription Status:** Monitor user subscription states and their impact on overall engagement.
* **Geographical & Market Analysis:** Compare user behavior across different countries to identify key markets and regional trends.
* **User Segmentation:** Group users based on behavioral and demographic parameters for advanced analysis.

---

## Tech Stack & Skills Demonstrated
* **Database:** SQL (Relational Database Management)
* **Key SQL Concepts Used:** 
  * Complex joins and subqueries
  * Window functions and aggregations
  * Common Table Expressions (CTEs)
  * Data filtering, grouping, and conditional logic
